Stitch Lab guide

A quick reference for the editor. Select a topic to expand it.

01Start a project+
Open artwork from your Mac, or use Files to reopen a locally saved project. The + beside document tabs creates a blank workspace. Import another image with Add image; each new image becomes a separate editable part.
02Select, move and align+
Use Select to move a part; drag its resize handles to scale it. Box select lets you select several parts. Use the crosshair Align menu to center or distribute parts. Pan with the Hand tool, two-finger scrolling, or Space-drag. Fit Hoop shows the selected hoop.
03Fills, outlines and fabric+
In Digitize, choose the stitch type, fill spacing, satin borders, underlay and pull compensation. For raster artwork you can invert which regions are stitched. Denser preview threads do not change the exported stitch spacing; change the actual fill settings before regenerating.
04Sewing order and cutting+
In Sequence, reorder parts and play through the sewing simulation. Check long jumps, trim thresholds and travel audit warnings. The optional inter-shape JEF cut markers require physical testing; they do not replace verification on the machine.
05Preview, save and export+
Switch between Finished embroidery, Stitch paths and Source artwork. Save the editable project as JSON, then export a JEF after confirming the hoop boundary and performing a machine trace. Always test on stabilized scrap before production.
06AI concepts and supported files+
AI garment mockups and embroidery-photo feedback require the included local Python server and a private, separately billed API key. AI images are concepts, not machine-accurate previews. PNG/JPG and JEF are supported; PES/PEC imports are supported for stitch-path inspection and editing. Native Wilcom EMB editing is unavailable.
